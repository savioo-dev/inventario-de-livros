📚 Inventário de Livros

Projeto desenvolvido com **HTML5 e CSS3**, com o objetivo de apresentar um inventário de livros em uma tabela organizada, permitindo visualizar títulos, autores, categorias, status de leitura e avaliações.

A aplicação foi desenvolvida como parte dos meus estudos em Desenvolvimento Front-end, com foco na estruturação semântica do HTML, estilização com CSS e aplicação de conceitos de responsividade e acessibilidade.

✨ Demonstração

O projeto apresenta uma interface simples e organizada, com identificação visual para cada status de leitura e avaliações representadas por indicadores circulares.

🛠️ Tecnologias utilizadas

- HTML5: estruturação do conteúdo utilizando elementos semânticos e tabelas.
- CSS3: estilização da interface, seletores de atributos, gradientes, dimensionamento e responsividade.

📋 Funcionalidades

- Exibição de livros em uma tabela organizada.
- Identificação do título, autor e categoria de cada livro.
- Classificação do status de leitura:
  - 🟢 Lido
  - 🟡 Em andamento
  - 🔴 Quero ler
- Representação visual das avaliações por indicadores circulares.
- Diferenciação visual das linhas conforme o status de leitura.
- Adaptação da interface para telas menores, com rolagem horizontal da tabela.
